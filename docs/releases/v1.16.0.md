# Puntovivo v1.16.0 — sesiones de escritorio y catálogo editable

## Why this release matters

El escritorio instalado podía volver a la pantalla de acceso después de unos
15 minutos: el navegador integrado no enviaba al servidor local la cookie que
necesitaba para renovar la sesión. Esta versión cambia la renovación local para
que el proceso principal de la aplicación gestione la credencial protegida, sin
alargar la vida del token de acceso ni guardar la contraseña en el formulario.

También facilita trabajar con un catálogo grande: buscar, seleccionar y exportar
productos, editar el archivo Excel y volver a importarlo con una vista previa.

## What changed

- **Continuidad de sesión en el escritorio.** Después de actualizar, inicia
  sesión una vez con tu contraseña para establecer la nueva credencial local. El
  acceso posterior se renueva mientras esa credencial siga siendo válida. La
  prueba automatizada cubre el servidor integrado, pero la permanencia durante
  una jornada real todavía debe verificarse en una instalación Windows.
- **Último correo utilizado.** El escritorio recuerda el correo de un inicio de
  sesión con contraseña exitoso y lo muestra tras salir o reiniciar. Al entrar
  otra persona, se actualiza. No recuerda contraseñas y no cambia el login web.
- **Importación y exportación de productos.** El catálogo permite localizar y
  seleccionar productos para exportar. Una exportación editable puede regresar
  como importación por ID, con previsualización y controles para impedir
  sobrescribir cambios concurrentes o datos de otro negocio.

## Before you use it

- Las pruebas de flujos web prerelease y el empaquetado, arranque y recuperación
  cifrada del candidato Windows terminaron correctamente. No equivalen a una
  prueba manual de sesión de más de 15 minutos en el instalador publicado.
- Revisa las diferencias en la vista previa antes de confirmar una importación;
  conserva una copia de tu archivo original. Una versión de producto cambiada
  desde la exportación debe resolverse antes de importar.
- El despliegue inicial de actualizaciones del escritorio es gradual (10 %).
  El instalador Windows no está firmado y puede mostrar una advertencia. La
  certificación fiscal y las pruebas con hardware físico siguen pendientes;
  consulta el [estado del proyecto](https://github.com/mateodev1/puntovivo/blob/main/docs/PROJECT-STATUS.md).
