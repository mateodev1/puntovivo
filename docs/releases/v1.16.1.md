# Puntovivo v1.16.1 — instaladores de la actualización del catálogo y la sesión

## Why this release matters

La página de v1.16.0 se publicó antes de subir los instaladores. GitHub impidió
adjuntarlos después porque la versión ya era inmutable, así que esa página no
ofrece una descarga instalable. v1.16.1 es la versión que entrega los cambios de
catálogo y sesión previstos para v1.16.0, con una publicación que comprueba los
artefactos antes de hacer pública la versión.

## What changed

- **Sesión continua en el escritorio.** El proceso principal renueva la sesión
  local sin depender de la cookie que no llegaba desde el origen empaquetado.
  Tras actualizar, inicia sesión una vez con la contraseña para establecer la
  credencial protegida. El token de acceso no dura más tiempo y la contraseña
  no se guarda.
- **Correo recordado.** El formulario del escritorio muestra el último email
  utilizado en un inicio de sesión exitoso. Persiste tras salir y reiniciar y
  cambia cuando entra otra persona; el login web no cambia.
- **Catálogo editable.** Puedes buscar y seleccionar productos, exportar un
  Excel editable y reimportarlo con vista previa. La actualización por ID
  comprueba la versión para evitar sobrescribir un producto cambiado entretanto.
- **Comprobación Linux.** La prueba del instalador usa un llavero temporal seguro
  para validar el login real, sin aceptar almacenamiento de credenciales en
  texto básico. El flujo de publicación ahora exige una release en borrador y
  no la hace pública si falla la creación de artefactos o el feed.
- **Dependencias revisadas.** Se actualizaron bibliotecas de red, validación y
  empaquetado tras detectar avisos nuevos en el control de seguridad previo a
  esta publicación. El control vuelve a pasar sin excepciones nuevas.

## Before you use it

- v1.16.0 no tiene instaladores; usa v1.16.1. El rollout del escritorio empieza
  al 10 %. En Windows, el instalador no está firmado y podría aparecer una
  advertencia. La disponibilidad de cada plataforma depende de que termine
  correctamente el workflow de publicación; las compilaciones macOS sin firma
  de Developer ID no se distribuyen.
- El empaquetado y el inicio de sesión Linux se validaron con el llavero seguro;
  aún hace falta comprobar manualmente que una instalación Windows permanezca
  autenticada más de 15 minutos durante el uso real.
- Revisa la vista previa antes de importar un catálogo y conserva el Excel
  original. La certificación fiscal y la validación con hardware físico siguen
  pendientes según el [estado del proyecto](https://github.com/mateodev1/puntovivo/blob/main/docs/PROJECT-STATUS.md).
